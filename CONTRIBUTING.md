# Contributing to Satellite Imagery Deep Learning

First off, thank you for considering contributing to this repository! It's people like you that make this community such a great resource.

## How Can I Contribute?

### Reporting Bugs or Issues
If you notice a broken link, a typo, or outdated information, please feel free to open an issue or submit a pull request fixing it.

### Suggesting New Projects or Papers
We are always looking to expand the repository with the latest and most relevant projects in Earth observation and deep learning. If you know of a project that isn't listed:

1. **Check if it's already there**: Use `Command + F` (Mac) or `CTRL + F` (Windows) to search the `README.md` first.
2. **Submit a Pull Request**: Follow the guidelines below to add the project to the appropriate section.

## Pull Request Guidelines

1. **Fork the repository** and create your branch from `main`.
2. **Format your addition correctly**: Look at how existing links are formatted in the README. Typically, we use the following format:
   ```markdown
   - [Project Name](link-to-project) -> A brief description of what the project does, highlighting the key methods or datasets used.
   ```
3. **Categorize correctly**: Make sure you add the new resource to the most relevant section (e.g., Classification, Segmentation, Code detection). If a new section is needed, feel free to create one!
4. **Keep it concise**: Descriptions should be short and informative.
5. **Commit your changes**: Write clear, descriptive commit messages.
6. **Open a Pull Request**: Provide a brief description of what you've added or changed.

## Code of Conduct
Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.

Thank you for contributing!
